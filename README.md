# regua-barsi
App Barsi V8 Ações "BEST Barsi", cotaçao, niveis, alertas sonoro e alerta popup quando app aberto ou em segundo plano.

Abra no navegador e adicione a sua área de trabalho, aparecerá opção para instalar no smartphone.

Abra o app regua barsi e configure as permições para receber alertas quando as ações atingirem os preços ou níveis pré estabelecidos.

Conta com três ou quatro fontes de cotação, quando uma falha a outra continua tentando.Também tem a possibilidade de usar offline, podendo atualizar cada preço direto no link do box clicando no icone de clips.

As informações são representadas de multiplas formas, em números, marcadores, preços, cores e porcentagens em tempo real com atualizações a cada 5 minutos ou acionando o botão atualizar.

A cor verde quando atinge o padrão barsi ou melhor, para quando for excelente preço para compra; o amarelo quando estiver proximo do preço padrão ideal para compra, e vermelho quando estiver com preço muito acima do que estabelece na régua barsi, preço não ideal para comprar uma ação.

Régua ou barra termo dinâmica:
-na base do card exibe o quanto o preço de uma ação está próximo ou distante do padrão estabelecido por Barsi. Os 3 marcadores escuros marcam  os intervalos percentuais fracionados enquanto o marcador principal de cor clara marca a proximidade, determinando a distância que o preço da ação está do padrão ao centro.

Marcações:
-o centro da régua colorida é o padrão.

Cores:
-as cores representam os níveis ou distancias em relação ao centro(padrão), a medida é calculada em porcentagem(%).

Regua Barsi = Método criado pelo investidor Barsi para compra de ações.
Ações BEST = Grupo de ações cujas caracteristicas correspondem ao padrão estabelecido por Barsi.
