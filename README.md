# regua-barsi
App Barsi V8 Ações "BEST Barsi", cotaçao, niveis, alertas sonoro e aleta popup quando app aberto.

Abra no navegador e adicione a sua área de trabalho, aparecerá opção para instalar no smartphone.

Abra o app regua barsi e configure as permições para receber alertas quando as ações atingirem os níveis pré estabelecidos na régua colorida.

A cor verde quando for excelente preço para compra, amarelo quando estiver proximo do preço padrão ideal para compra e vermelho quando estiver com preço muito acima do que estabelece a régua barsi como sendi ideal para comprar uma ação.

Régua ou barra termo dinâmica na base do card exibe o quanto o preço de uma ação está próximo ou distante do padrão estabelecido por Barsi. Os 3 marcadores escuros marcam  os intervalos percentuais fracionados enquanto o marcador principal de cor clara marca a proximidade, determinando a distância que o preço da ação está do padrão ao centro.

Os 3 box: Excelente/verde, Amarelo/Próximo e Vermelho/Acima
